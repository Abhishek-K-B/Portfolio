# Abhishek K B — Developer Portfolio

A responsive, static portfolio built with HTML, CSS and JavaScript. No build tools, PHP, or backend required.

## Preview locally
Open `index.html` in a browser. For best results, use VS Code Live Server or `python -m http.server 8000` and visit `http://localhost:8000`.

## Deploy on GitHub Pages
1. Create a public GitHub repository (for example `portfolio`).
2. Upload **the contents of this folder** to the repository root (`index.html`, `styles.css`, `script.js`, `assets/`).
3. Go to **Settings → Pages → Build and deployment**.
4. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** and save.
5. Wait for deployment and open `https://YOUR-USERNAME.github.io/portfolio/` (replace YOUR-USERNAME with your actual GitHub username).
6. Add the URL to LinkedIn's Featured section and your resume.

## Before publishing
- Verify the resume PDF and education dates/SGPA.
- Confirm project descriptions and internship details.
- Replace illustrative project artwork with actual screenshots if available.
- Add GitHub repo and live demo links **only when verified**.
- Test email and social links.
- Optionally add a real social preview image (`og:image`) after publishing.

The fonts are loaded from Google Fonts; system fonts are used when offline.
